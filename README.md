# 終末盤戯（アポカリプター）

『神血の救世主』（原作：江藤俊司、作画：疾狼）の作中ゲームをWebで再現したボードゲームです。

## 公開のしかた（GitHub Pages）

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロードする
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べる
4. スマホでそのページを開き、共有メニューの「ホーム画面に追加」でアプリのように起動できる

ファイルを更新したら、`sw.js` の `VERSION` を上げると利用者側にも新しい版が届きます。

## ファイル

| ファイル | 中身 |
|---|---|
| `engine.js` | ルール（駒の動き、魂ポイント、救世主、縮退、進化）とCPU |
| `app.js` | 画面、演出、効果音、保存 |
| `style.css` | 見た目 |
| `index.html` | 画面の骨組み |
| `sw.js` / `manifest.webmanifest` | ホーム画面に追加・オフライン対応 |
| `icons/` | アプリアイコン |
| `assets/` | 差し替え用の駒画像を置く場所 |

## 名前を変えるとき

`app.js` の先頭の `APP`（タイトル、英字名、キャッチコピー）と、`index.html` / `manifest.webmanifest` の名前を変えます。
駒の名前は `engine.js` の `TYPES` と `P_FORMS`、`app.js` の `KIND_CH` と `KIND_NAME` にあります。

## 駒を画像に差し替えるとき

`assets/` に画像（正方形、背景透過のPNGがおすすめ）を置き、`app.js` 先頭の `PIECE_IMAGES` に登録します。

```js
const PIECE_IMAGES = {
  'K_w': 'assets/K_w.png',
  'K_b': 'assets/K_b.png',
};
```

キーは「駒_陣営」です。登録していない駒は今までどおりの紋章で表示されます。

| 記号 | 駒 | 記号 | 駒 |
|---|---|---|---|
| K | 魔王 | R | 死神 |
| A | 天使 | N | 騎士 |
| F | 堕天使 | P | 信徒 |
| I | 審問官 | P1 | 狂信者 |
| D | 龍王 | P2 | 凶獣 |
| S | 星喰い | P3 | 終末の獣 |

陣営は `w`（白）と `b`（黒）。全部そろえると24枚です。

## 補助表示とチュートリアル

- 補助表示（設定で切り替え）：狙われている自分の駒が赤く脈打ち、駒を選ぶと取られる危険があるマスが赤い点になる。魔王が狙われているときや、縮退が近いのに魔王が外周にいるときは警告が出る
- チュートリアル：移動・捕獲・詰み・縮退から逃げる・救世主の5レッスン。`app.js` の `LESSONS` で内容を変えられる
- 対局画面の「ルール早見表」：駒の動きと特殊ルールの一覧

## 漫画で説明のない部分の解釈

- 信徒の進化は、両陣営の救世主の降臨回数の合計で決まる（どちらが降臨しても両陣営が進化。漫画の描写に合わせた）
- 救世主の3ターンは、降臨した側の手番3回
- 救世主を出すと魂ポイントは0に戻る。20に達すると自動で降臨
- 相手の救世主が発動中でも自分の救世主は降臨する
- 狂信者以降の信徒が、どちらかの陣営で2体取られるごとに縮退（縮退で落ちた分は数えない）
- 凶獣・終末の獣の「斜め1マス」は斜め前の2マス
- 騎士の救世主中は縦3・横1のL字
- 信徒が最後列に着いても何も起きない
- 動かせる駒がなくなった側は負け（独自ルール）
- 10秒切れモード（対局前に選択）：自分の手番に10秒以内に指せなければ負け。救世主の演出中と中断メニューを開いている間は止まる
