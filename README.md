# 崩盤（COLLAPSE）

17×17の盤で戦う2人対戦のボードゲームです。相手の覇王を討つか、崩落で盤の外に落とせば勝ち。
魂ポイントを20貯めると覚醒し、覚醒が終わるたびに盤の外周が崩れ落ちていきます。

## 公開のしかた（GitHub Pages）

1. GitHub で新しいリポジトリ（Public）を作り、このフォルダの中身をすべてアップロードする
2. Settings → Pages → Branch を `main` / `(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べる
4. スマホでそのページを開き、共有メニューの「ホーム画面に追加」でアプリのように起動できる

更新するときは、変わったファイルを同じ名前でアップロードし直せば上書きされます。`sw.js` の `VERSION` を上げると、ホーム画面に追加した人にも新しい版が届きます。

## ルールのまとめ

- 白が先手。黒は魂ポイント2から始まる
- 魂ポイント20で自動的に覚醒し、ポイントは0に戻る
- 覚醒した側の手番3回、影翼・槍兵・蒼龍・暴嵐・死鎌・天馬の移動距離が1.5倍
- 相手が覚醒している間でも、自分も覚醒する
- どちらが覚醒しても、両陣営の兵卒が進化する（段階は覚醒回数の合計）
- 覚醒が終わると崩落が起き、盤の外周1周が消える。上の駒は消滅し、覇王なら負け
- 進化した兵卒が、どちらかの陣営で2体取られるごとにも崩落する（崩落で落ちた分は数えない）
- 動かせる駒がなくなった側は負け
- 10秒切れモード（対局前に選択）：自分の手番に10秒以内に指せなければ負け

## 名前や画像を変えるとき

- ゲーム名：`app.js` 先頭の `APP`、`index.html` の `<title>`、`manifest.webmanifest`
- 駒の名前：`engine.js` の `TYPES` と `P_FORMS`、`app.js` の `KIND_CH` と `KIND_NAME`
- 駒の画像：`assets/` の `K_w.webp` などを差し替える（陣営は `w` 白 / `b` 黒、全24枚）。登録は `index.html` の `window.PIECE_IMAGES`。登録がない駒はコードで描いた紋章になる
